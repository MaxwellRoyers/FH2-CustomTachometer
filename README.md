# FH2 Custom Tachometer v0.8.0

### Features
- Custom analog tachometer HUD.
- Customizable speed display.
- RPM needle with live game data.
- Custom gear indicator.
- Shift light indicator.
- ABS, TCR and STM indicators.
- Custom XAML-based HUD design.

### Requirements
- Forza Horizon 2 (PC)
- FH2 ModPlatform.NET

### Installation
1. Download the release ZIP.
2. Extract `CustomTachometer.cs`.
3. Place it inside `fh2-mods-dotnet/scripts/`.
4. Launch Forza Horizon 2 using Azimuth.
